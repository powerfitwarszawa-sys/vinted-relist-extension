Bezpieczne tempo API

Jeśli relist przejdzie na awaryjną ścieżkę API, używaj odstępu liczonego w minutach. Seria automatycznie zatrzyma się po błędzie API 401, 403 lub 429.

Wskazówki

  • Większe odstępy ograniczają ryzyko szybkiej, powtarzalnej serii działań.
  • Dodatek losowy różnicuje odstępy między kolejnymi ofertami.
  • Tryb szkicu otwiera ofertę do ręcznej kontroli, bez klikania akcji.
  • Skan pobiera garderobę zalogowanego konta przez bieżącą sesję Vinted, a po błędzie używa tylko widocznych kart.
